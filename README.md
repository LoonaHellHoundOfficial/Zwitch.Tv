# 🦊 Welcome to Zwitch.tv!

**Discover live streams. Find new creators. Enjoy watching together.**

Zwitch.tv is an independent Twitch discovery experience with a neon-purple design, a friendly fox mascot, and a paw-print visual identity. Its goal is to make discovering streaming content more enjoyable.

Zwitch.tv is designed to help viewers explore live Twitch streams, browse games and categories, search for channels, and discover creators they might not have found otherwise. The project aims to bring these discovery features together in one easy-to-use website.

One of the main ideas behind Zwitch.tv is accessibility. Visitors are intended to be able to browse available content without signing in. Supported Twitch streams can be viewed through embedded players, making it easier to explore creators and their content.

The project also has a distinctive visual identity. Its purple and neon styling, fox mascot, and paw-print details help give Zwitch.tv its own personality. The goal is to create a welcoming experience for viewers and streaming communities.

The Zwitch.tv pawprint is intended to identify Twitch accounts that Twitch confirms as Partners. It is a visual indicator based on Twitch Partner information, not a separate verification program. A normal Zwitch.tv login does not qualify an account for the Twitch Partner pawprint. Some account and sign-in features may remain marked **Coming Soon** while development continues.

## 💻 Getting Started with Zwitch.tv

Zwitch.tv can be downloaded and run locally on Windows. It uses Node.js and includes a `Start-Zwitch.bat` launcher.

**🛑 IMPORTANT: When you download and extract Zwitch.tv, do not move, rename, delete, or modify any files or folders before following the setup instructions.** Keep the downloaded folder structure as it is.

We've included **two visual setup guides** alongside the `zwitch-project` folder, not inside it:

1. **Zwitch.tv Neon Local Setup Guide** — Follow the pictures step by step to prepare and launch Zwitch.tv.
2. **Neon Purple Twitch ID Safety Guide** — Learn how to protect your Twitch credentials and keep your private information safe.

**Open both guide images and follow the steps shown in them in order.** They will walk you through getting Zwitch.tv working on your Windows computer.

## 🔐 Security Matters

Security is important to this project. Keep your private `.env` file and Twitch Client Secret out of GitHub, screenshots, and public conversations. Only the example configuration file, `.env.example`, should be included in the public repository.

Never publish private credentials. If a Client Secret is exposed, revoke or regenerate it through the Twitch Developer Console.

## 🗑️ Uninstalling Zwitch.tv

Want to remove Zwitch.tv from your computer? No complicated uninstaller is needed!

1. Close Zwitch.tv and its running terminal window.
2. Find the downloaded Zwitch.tv folder.
3. Right-click the folder and select **Delete**, or drag it into the **Recycle Bin**.
4. Empty the Recycle Bin if you want to permanently remove the files.

That's it! Zwitch.tv is removed from your computer.

**Note:** If you want to keep your Twitch setup credentials or other personal files, make a private backup before deleting the folder.
